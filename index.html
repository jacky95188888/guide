你的第一個網路工具

沒寫過程式、只有一支手機也沒關係。照著這份做,你會親手做出一個能放上網、別人打開就能用的工具。卡住的地方我都先幫你寫好解法了。

手機或電腦都能做

整個過程分成三大關:① 準備帳號和 AI → ② 開一個免費網站空間 → ③ 把工具貼上去。每一步都有「卡住了?」的提示,先自己照著走,真的卡死再傳訊息問三寶爸。慢慢來,做完你就是會做工具的人了。

第一關 · 準備工具
1

下載 Claude(幫你寫程式的 AI)

  1. 打開手機 App Store
  2. 搜尋 Claude(注意是 Claude,不是 cloud)
  3. 找到橘色花朵圖示、「Claude by Anthropic」,按「取得」下載
  4. 打開、註冊登入(用 Email 或 Google 帳號都行)
搜尋打錯成 cloud 也沒關係,通常還是找得到。認圖示:橘色底、白色像花/星星的標誌就對了。
免費就夠:Claude 免費下載、免費用。裡面有付費進階版,但做工具用免費的完全足夠。
2

註冊一個 GitHub 帳號(放網站的地方)

  1. 用瀏覽器(Safari 或 Chrome)開 github.com
  2. 按 Sign up(註冊),用 Email 設定帳號密碼
  3. 記住你的帳號名稱,等一下網址會用到
重要:後面所有 GitHub 的操作,都建議用瀏覽器開 github.com 來做,不要用 GitHub App。App 是簡化版,很多設定(像把網站公開)它根本沒有,會讓你白卡半天。
第二關 · 開一個免費網站空間
3

開一個新倉庫(你的網站資料夾)

  1. 登入後,按右上角的 「+」 → New repository
  2. Repository name 取一個英文名字,例如 my-tool
  3. 下面選 Public(公開)— 這很重要,免費網站一定要公開
  4. 勾選 Add a README file
  5. 按綠色的 Create repository
一定要選 Public!如果不小心開成 Private(私人),免費網站功能用不了,後面會卡住。下一步教你怎麼補救。
4

確認倉庫是「公開」的

如果第 3 步已經選了 Public,這步可以跳過。如果不小心開成 Private(名字旁邊有鎖頭),照下面改:

  1. 用瀏覽器開 github.com/你的帳號/倉庫名/settings
  2. 頁面一直往最下面拉到底,找到紅色框 Danger Zone
  3. 找 Change repository visibility → 點 Change visibility
  4. 選 Make public(改成公開)
  5. 按「I have read and understand these effects」
  6. 它叫你打倉庫全名確認,照打 你的帳號/倉庫名,確認
跳出來的那些英文(程式碼會被大家看到…)不用怕,那正是免費網站要的,放心確認。改好後鎖頭會消失。
別按 Upgrade!過程中如果看到「Upgrade」按鈕,那是要付錢的,不要按。我們全程走免費。
5

開啟免費網站功能(GitHub Pages)

  1. 進倉庫,點上面那排的 Settings(設定/齒輪)
  2. 左邊選單找 Pages
  3. Source(來源)選 Deploy from a branch(從分支部署)
  4. Branch(分支)選 main,旁邊資料夾保持 / (root)
  5. 按 Save(儲存)
Source 預設可能是「GitHub Actions」,太複雜,記得改成「Deploy from a branch」就好。
Save 按鈕變灰色按不動?那是正常的,代表已經存好了,不用再按。
會看到網址:設定好後,Pages 頁面上方會出現一行網址,長這樣 https://你的帳號.github.io/倉庫名/。記下來,這就是你的網站。現在打開還是空的,正常,因為工具還沒貼。
第三關 · 把工具放進去
6

叫 Claude 幫你寫工具

打開 Claude,把你想做的工具講給它聽,加上這幾個關鍵要求:

  1. 「幫我做一個 ___ 的工具」(填你想做的,例:貼文產生器、計算機)
  2. 「請做成單一個 HTML 檔,全部寫在一起」
  3. 「不要用 alert、confirm、prompt」(放網頁後這些會失效)
  4. 「給我完整可以直接複製的程式碼,不要分段」
越小越好:第一個工具不要貪心。一個「填欄位、按一下、出結果」的小工具最好做、最快有成就感。
7

把程式碼貼進網站(最後一步!)

貼之前一定要先做:關掉瀏覽器的「自動翻譯」!
Chrome / Safari 的自動翻譯會在你貼程式碼時,偷偷把英文指令翻成中文,程式就壞了,而且你完全不會發現。動手前先把這個網站的翻譯關掉。
  1. 關掉自動翻譯後,進你的倉庫
  2. 按 Add file → Create new file
  3. 檔名一定要打 index.html(一個字都不能錯)
  4. 把 Claude 給你的程式碼整段貼進去
  5. 往下按 Commit changes(儲存)
  6. 等一兩分鐘,打開你的網址 → 工具就出現了!
打開網址沒東西/出現 404?等個 2-3 分鐘再重新整理。剛 Commit 完需要一點時間才會更新。
以後要改:回 GitHub 點 index.html 旁的鉛筆圖示,改完再 Commit,網頁過一兩分鐘自動更新。
你的工具上線了 🎉
https://你的帳號.github.io/倉庫名/

把這個網址丟進 LINE、FB,任何人點開就能用。免費、永久、隨時可改。
